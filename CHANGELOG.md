# Changelog

## 1.0.0 — Initial public release candidate

Made by Upkopp for people collecting source material before a website rewrite.

- Read original page headings, paragraphs, metadata, and declared dates.
- Explore headings, landmarks, and sections in Page map.
- Capture page text and review incomplete results before exporting.
- Export Content and Page map together as one compact JSON file.
- Download page images in one ZIP containing one folder; include alt text and captions in the research workflow.
- Inspect page-level indexability and social metadata as supporting context.
- Use the popup, larger window, or side panel with bundled Poppins and theme preferences.
- Process collected material locally, without accounts, analytics, or AI services.

This is the first public version. It is not yet listed in the Chrome Web Store.

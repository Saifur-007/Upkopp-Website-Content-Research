# Security

The current release candidate is 1.0.0. No security response-time guarantee is offered.

Do not publish credentials, private captures, or exploitable details in a public issue. Once the repository is public, use GitHub's private vulnerability reporting if enabled. A private maintainer contact must be configured before store publication; see docs/RELEASE.md.

The extension reads user-selected pages, renders source strings as text, bounds collection and image download sizes, and executes only bundled scripts. Exported content remains untrusted source material. Image files retain their original formats; review where and how you open or redistribute them.

# Contributing

Bug reports and product feedback are welcome through this repository's Issues tab once it is published. Include a public example and steps to reproduce; never attach private captured content.

Upkopp retains ownership and has not granted an open-source reuse license. Discuss code contributions with the maintainer before submitting them; contribution and licensing terms must be agreed explicitly.

Maintainer development uses plain JavaScript, HTML, and CSS. Node.js 22 or newer runs the checks; no dependency installation is needed. Run `npm run verify`, follow the 4px spacing scale, and keep source text rendering separate from markup execution. Do not introduce telemetry, external AI, remote executable code, or new permissions without a documented product decision.

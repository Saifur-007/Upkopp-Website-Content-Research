# First public release: 1.0.0

Status: release candidate prepared locally. Nothing has been pushed to GitHub, uploaded to Google, or published. Store acceptance is not guaranteed.

## Which files to use

- Repository / Load unpacked: this `upkopp-content-research` folder with `manifest.json` at its root.
- Store upload: `dist/upkopp-content-research-1.0.0.zip`, generated by `npm run verify`.
- Listing copy: `store/LISTING.md`.
- Product and launch plan: `store/POSITIONING.md`.
- Privacy policy source: `src/help/privacy.html`.
- Brand artwork: `store/assets/`.

Do not upload a ZIP of the entire repository to the store. The package builder uses a runtime allowlist. `dist/` is ignored by Git; attach the verified ZIP to a GitHub release manually if desired.

## Before submitting

- [ ] Add the real Upkopp homepage and support contact to the listing, help page, privacy policy, and SECURITY.md. The owner will provide these later.
- [ ] Host an HTTPS privacy-policy URL that opens without login. Replace the contact placeholder first. Host its relative CSS/font/logo assets too, or publish the same text in your website's own template.
- [ ] Configure the developer account, publisher identity, account verification, and distribution settings. No account setup was performed here.
- [ ] Complete data disclosures: website content and page URLs are handled even when they stay local. Justify every permission against shipped features. Remote executable code: no.
- [ ] Confirm distribution rights for shipped code and supplied Upkopp artwork. Font notices are included; reference-extension bundles are excluded.
- [ ] Load the final package in native Chrome and complete TESTING.md, especially origin prompts, side panel, cancelled captures, and actual ZIP downloads.
- [ ] Capture real screenshots of the final extension. At least one is required: 1280×800 or 640×400, full bleed. Use public/sample content you have permission to show. Do not present the simulated preview as a real extension screenshot.
- [ ] Provide the 128×128 PNG icon and 440×280 PNG promotional tile. Editable artwork is in store/assets; review final raster assets before uploading.
- [ ] Run `npm run verify` again after code, contact, or asset changes, then use the new ZIP and checksum.
- [ ] Upload the ZIP, fill out the listing/privacy fields, and submit for review. No script in this project auto-publishes.

## GitHub

Create a repository named `upkopp-content-research` under your chosen account, then push this folder's contents. No repository URL is invented or configured. Keep the repository root at the same level as `manifest.json`.

Included CI verifies Windows and Linux with read-only permissions and no publishing secrets. Enable private vulnerability reporting and add the support contact before public distribution. No source reuse license is granted.

Use `v1.0.0` after internal release approval. Future updates must increment manifest and package versions together. Version 1.0.0 is for a new public listing; it is not intended as a downgrade of an existing published item.

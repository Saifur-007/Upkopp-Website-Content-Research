Privacy policy

Applies to Upkopp — Website Content Research, version 1.0.0. Updated 8 September 2026.

Purpose and data use

Upkopp helps you collect original website content and page structure for copywriting research. When you open its interface on a website, it reads that page's URL, title, visible text, headings, page structure, metadata, and image references. A scrolling capture begins only when you start it. Optional embedded-page access is requested when needed.

The content you choose to capture may include personal or confidential information displayed on that page. Upkopp excludes form controls and editable fields from its text overview; it is not a sensitive-data redaction tool. Review your source page and exported files before sharing them.

Processing and storage

Page content is processed locally. Upkopp has no account system, developer-operated backend, analytics, advertising, or AI service. It does not upload captured content to Upkopp. It does not sell data, use it for advertising, or use it to determine creditworthiness or lending eligibility.

Capture results and image-export progress use temporary browser session storage. They clear when Chrome or the extension restarts. Settings and map preferences persist locally. The popup and page-map readers also hold temporary in-memory data. Downloaded text, JSON, and ZIP files remain on your device until you delete them.

Network requests

Opening Indexability requests the current page HTML and robots.txt from that site's origin, using its existing session where applicable. Image and social-image previews can request resources from the original hosts. ZIP exports request the selected image hosts after you grant access; those fetches omit cookies and referrers and reject redirects. Sites and resource providers can see ordinary request information such as your IP address. Upkopp does not control their privacy practices.

Text capture can cause the website to load additional content as it scrolls. Fonts and executable code are bundled locally. No remote executable code is downloaded.

Your controls

Choose which page to inspect and when to capture or export. Review partial captures before saving. Use Forget session copies in Text capture to remove retained text results, or restart Chrome to clear temporary session data. Revoke optional site access in Chrome's extension settings. Uninstalling removes extension storage but does not delete downloaded files.

Limited use

Upkopp limits its use of website content and page URLs to the research features you use. It does not transfer collected page content to advertisers, data brokers, or unrelated services.

Contact and changes

Public Upkopp support contact details must be added to this policy before store publication. This local release candidate has not been published. Material changes to data use will be reflected in this policy and the extension's store disclosures.

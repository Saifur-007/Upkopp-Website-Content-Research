Help and shortcuts

Use the arrow keys to move through the map. Enter scrolls to an item. Left and right collapse and expand branches. Home and End move to the first and last item.

Search keeps parent headings for context. Copy map copies the filtered outline, including collapsed branches. Text capture downloads the original page copy separately.

Warnings identify things to review; they are not a complete accessibility or SEO audit. Sections follows source containers, not the old HTML5 outlining algorithm.

Resize or move this native side panel using Chrome’s controls. Map display preferences are saved on this device.

These shortcuts work while the map has focus. The toolbar shortcut can be changed at chrome://extensions/shortcuts.

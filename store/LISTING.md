## Name

Upkopp — Website Content Research

## Short description

Collect website text, headings, and image references for copywriting research. Export content and page structure together.

## Full description

Start your next website rewrite with the source.

Upkopp helps copywriters, content strategists, and web designers collect the words and structure already on a website. Review the page, understand its hierarchy, and save useful source material for your writing workflow.

READ THE EXISTING COPY

See the title, description, headings, paragraphs, and declared publication dates. Copy page text or just its headings. Use Page map to explore headings, landmarks, and sections, then jump to the part you need.

EXPORT CONTENT AND STRUCTURE TOGETHER

Download one JSON file containing Content and Page map. It keeps original wording and useful structure without raw page HTML or image bytes. Use Text capture for a scrolling pass saved as plain text. Incomplete captures explain their limitations and wait for you to choose an export.

GATHER IMAGE REFERENCES

Review page images, alt text, and captions. Download all images or a selection as one ZIP containing one folder of image files. An incomplete archive includes a short report explaining skipped resources.

UNDERSTAND PUBLISHING CONTEXT

Inspect social-sharing metadata and page-level indexability signals while reviewing content. These support research; they are not a full SEO audit or proof of indexing.

WORK IN YOUR BROWSER

Use the popup, side panel, or larger window. Choose your theme and export preferences. Poppins and executable code are bundled in the extension.

MADE BY UPKOPP

Selected page content is processed locally. No Upkopp account, analytics, advertising, or AI service is required. Page checks and image requests contact the original sites. Optional access is requested for embedded pages or image downloads when needed.

Open a website, click Upkopp, and begin with Content. Bring exported source material into your writing process; Upkopp does not generate or rewrite copy.

Some protected pages, embedded content, and image resources cannot be read or downloaded. Keep the source tab selected during capture and review coverage notes before using an export.

## Reviewer instructions

No account, payment, API key, or external service is needed. Open Upkopp on a normal public website and inspect Content and Page map. Export JSON to see both sections in one file. Start Text capture and keep the source tab selected. In Images, choose Download all images, grant the named resource origins if prompted, and inspect the single-folder ZIP. Settings controls local preferences. A protected Chrome page should show an explanatory message.

The publisher must check the final ZIP in native Chrome before submission. See [release checklist](../docs/RELEASE.md).
